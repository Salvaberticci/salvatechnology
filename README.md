# Salva Technology

Sitio web profesional de Salva Technology - Experiencias Digitales Inmersivas

## Estructura del Proyecto

```
salvatechnology/
├── assets/           # Recursos estáticos
│   ├── css/         # Hojas de estilo
│   ├── js/          # Archivos JavaScript
│   ├── img/         # Imágenes
│   └── fonts/       # Fuentes personalizadas
├── src/             # Código fuente de la aplicación
│   ├── Controllers/ # Controladores
│   ├── Models/      # Modelos de datos
│   ├── Views/       # Vistas/plantillas
│   └── config/      # Archivos de configuración
└── public/          # Punto de entrada público
    └── index.php    # Archivo de entrada principal
```

## Requisitos

- PHP 8.0 o superior
- Servidor web (Apache/Nginx)
- MySQL 5.7 o superior (opcional, según necesidades)

## Instalación

1. Clonar el repositorio
2. Configurar el servidor web para que apunte a la carpeta `public/`
3. Configurar permisos de escritura en las carpetas necesarias
4. Instalar dependencias (si las hay)

## Desarrollo

Para comenzar a desarrollar:

1. Clonar el repositorio
2. Instalar dependencias con Composer (si se agregan)
3. Configurar el entorno de desarrollo
